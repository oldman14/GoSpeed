# Synthesize Engine and Arcade Sound FX Procedurally via Web Audio API

We will synthesize vehicle engine audio and sound effects procedurally via the browser's Web Audio API instead of loading external sound files. This eliminates audio asset loading delays, network failures, and CORS issues, while enabling continuous, glitch-free pitch scaling coupled 1:1 with kart RPM, throttle, drift screeching, and nitro boost intensity.
