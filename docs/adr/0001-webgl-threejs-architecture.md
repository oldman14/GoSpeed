# Adopt WebGL and Three.js for Browser-First 3D Arcade Racing

We will build GoSpeed as a browser-first 3D web application using Three.js and TypeScript, rather than using a desktop game engine (Godot/Unity) or a native Go rendering engine. This enables instant zero-install playability, frictionless distribution, and rapid iteration on arcade drift physics and visual shaders while retaining high frame rates via WebGL.
